# Raw data

Files in this folder come from the UCI Machine Learning Repository, dataset "South German Credit (UPDATE)":
https://archive.ics.uci.edu/dataset/573/south%2Bgerman%2Bcredit

- `SouthGermanCredit.asc`: the data (1,000 credits, 20 predictors and the target `kredit`)
- `codetable.txt`: the meaning of the codes
- License: Creative Commons Attribution 4.0 (CC BY 4.0). The full citation and background are on the UCI page.

I did not change these files. The column names are in German, and `01_prepare_data.py` renames them.
